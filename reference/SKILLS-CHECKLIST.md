# Self-assessment checklist

Check only when you can explain, demonstrate and test the skill yourself.

## Python essentials
- [ ] Explain `str` vs `bytes`, identity vs equality, mutable vs immutable.
- [ ] Use collections and analyze time/memory complexity.
- [ ] Write reusable functions with safe defaults and annotations.
- [ ] Stream large files and parse malformed JSON/CSV.
- [ ] Handle errors correctly with specific exceptions.
- [ ] Write unit tests, fixtures and mocks.
- [ ] Apply composition, protocols and dependency injection.
- [ ] Use bounded async I/O with timeouts and cancellation.
- [ ] Package a CLI and run it in a virtual environment.
- [ ] Profile memory and CPU before optimizing.

## Secure development
- [ ] Obtain scope/authorization and identify trust boundaries.
- [ ] Handle paths, subprocess calls and SQL parameters safely.
- [ ] Distinguish hashing, MAC, encryption, signature and password hashing.
- [ ] Use `secrets` and validated TLS appropriately.
- [ ] Implement AuthN and per-object AuthZ tests.
- [ ] Explain dependency/supply-chain risks and CI controls.
- [ ] Manage secrets and redact sensitive logs.

## Defensive cybersecurity
- [ ] Explain networking layers and TCP/UDP message semantics.
- [ ] Parse offline PCAPs and explain encrypted-traffic limitations.
- [ ] Normalize and correlate synthetic authentication events.
- [ ] Evaluate alert false-positive/false-negative tradeoffs.
- [ ] Preserve local lab evidence and write an incident timeline.
- [ ] Triage an inert file without claiming entropy proves malware.
- [ ] Normalize indicators with source, confidence and expiry.
- [ ] Draft a least-privilege read-only cloud audit plan.
- [ ] Write a scoped, evidence-based remediation report.

## Portfolio readiness
- [ ] Publish 3 independently coded, testable defensive tools.
- [ ] Each has README, CLI, fixtures, tests, limitations and ethics notes.
- [ ] Explain one design tradeoff and one false positive in an interview.
- [ ] Review your work with another engineer or instructor.
- [ ] Never include secrets, private logs or unauthorized targets.
