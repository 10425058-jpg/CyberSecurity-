# Authoritative and recommended references

Prefer primary/official documentation. Links may evolve; always confirm the currently supported version. Some external courses have optional paid tiers.

## Books and courses to look up through official publisher pages
- Python official tutorial and real-world exercises before advanced automation.
- University networking and operating-system courses (packet model, processes, permissions).
- OWASP web security guidance, threat modeling and secure architecture.
- Incident response and forensics courses with explicit isolated lab requirements.

**Reading policy:** verify publication/version dates for security guidance. Do not copy proprietary course text into the repo. Summarize in your own words, attribute sources and link to originals.
