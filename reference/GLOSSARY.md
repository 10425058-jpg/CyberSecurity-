# Bilingual-friendly English technical glossary (English definitions)

| Term | Meaning |
|---|---|
| API | Interface exposing operations/data to other programs |
| API contract | Agreed request/response format, behavior and errors |
| AST | Abstract syntax tree representing program structure |
| Authentication | Establishing who or what is requesting access |
| Authorization | Determining whether that identity may perform an action |
| AEAD | Encryption giving confidentiality and integrity for ciphertext and authenticated associated data |
| Backpressure | Slowing/limiting production when consumers cannot keep up |
| Binary | Data represented as bytes rather than Unicode text |
| Buffer | Temporary storage for I/O or computation |
| Bytecode | Intermediate instructions executed by Python's VM in common implementations |
| CIDR | Prefix notation for IP networks |
| CI/CD | Continuous integration and delivery/deployment |
| CLI | Command-line interface |
| CVE | Public identifier for a disclosed vulnerability |
| CVSS | Standardized vulnerability severity scoring system |
| DFIR | Digital forensics and incident response |
| DNS | Domain Name System for host/service name resolution |
| EDR | Endpoint detection and response |
| False positive | Benign activity incorrectly flagged as suspicious |
| False negative | Harmful activity missed by a detector |
| Fuzzing | Supplying varied or malformed inputs to test robustness |
| GIL | Global interpreter lock; implementation/build specific |
| Hash | Fixed-size digest computed from data |
| HMAC | Keyed hash message authentication code |
| IOC | Indicator of compromise, which requires contextual validation |
| Iterator | Object yielding successive elements via iteration protocol |
| JSONL | One JSON document per line |
| KDF | Key derivation function |
| Least privilege | Minimum permissions necessary for the task |
| MAC | Message authentication code |
| MFA | Multifactor authentication |
| Mitigation | Action that reduces vulnerability or risk |
| OOP | Object-oriented programming |
| OSINT | Open-source intelligence based on publicly available sources |
| PCAP | Packet capture file format |
| PEP | Python Enhancement Proposal |
| Precision | True positives divided by all positive predictions |
| Recall | True positives divided by actual positive cases |
| ReDoS | Regular expression denial of service |
| RBAC | Role-based access control |
| SIEM | Security information and event management |
| SOC | Security operations center |
| SOAR | Security orchestration, automation and response |
| SSRF | Server-side request forgery |
| STIX | Structured Threat Information Expression |
| TAXII | Trusted Automated Exchange of Intelligence Information |
| TTP | Tactics, techniques and procedures |
| Threat model | Structured assessment of assets, threats, boundaries and controls |
| TLS | Transport Layer Security |
| Type hint | Annotation describing intended types; not runtime enforcement |
| UTC | Coordinated Universal Time |
| venv | Python virtual environment, not a security sandbox |
| YARA | Rule-based pattern matching tool for artifacts |
| Zero Trust | Security approach requiring explicit verification and least privilege |
