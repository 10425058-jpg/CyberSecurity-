# Cybersecurity Career Paths and Certifications

## Career paths
| Track | Typical work | Core skills | Portfolio evidence |
|---|---|---|---|
| SOC Analyst / Blue Team | Monitor alerts, investigate logs, triage incidents | Windows/Linux logs, SIEM, networking, ATT&CK | SIEM lab, detection notes, investigation reports |
| Penetration Tester / Red Team | Authorized security testing and reporting | Networking, Linux, web security, scripting, methodology | Lab reports, web assessment, scoped test docs |
| Security Engineer | Build and maintain controls | Systems, networking, IAM, endpoint, cloud, automation | Secure architecture, hardening scripts |
| Application Security | Secure software delivery | Secure coding, web/API, code review, SAST/DAST/SCA, threat modeling | Threat model, code review findings, secure CI |
| Cloud Security | Secure cloud identities, workloads, networks and data | IAM, cloud networking, logging, key management, IaC | Secure cloud architecture and policies |
| DFIR / Malware Analysis | Investigate incidents and malicious artefacts | OS internals, memory/disk/network forensics, scripting | Forensic reports using benign datasets |
| GRC / Risk | Policies, audits, risk assessment, controls | Frameworks, writing, evidence, privacy, communication | Risk register, control mapping, policy |
| DevSecOps | Integrate security into delivery pipelines | CI/CD, containers, code scanning, secrets, IaC | Secure pipeline demo |

## Choosing a track
- Monitoring, evidence, investigation and response → Blue Team/SOC.
- Methodical testing, application behaviour and findings → Pentesting/AppSec.
- Building secure platforms and automation → Security Engineering/Cloud/DevSecOps.
- Structured controls, risk, policy and audit evidence → GRC.
Employability usually requires depth in one role, not shallow familiarity with every subfield.

## Beginner strategy
1. Build IT, Linux and networking foundations.
2. Complete beginner labs and one portfolio project.
3. Choose a broad entry-level credential only if it supports a real objective.
4. Choose one role-specific credential after trying Blue and Red Team.
5. Delay senior/management credentials until experience and eligibility requirements are met.

## Job-readiness evidence
Explain fundamentals without notes; operate role tools; investigate and explain reasoning; write reproducible notes; understand authorization/privacy/responsible disclosure; publish a few high-quality projects.

## Germany-oriented preparation
Develop technical English and German workplace communication; gain enterprise identity/Windows, cloud and security operations familiarity; learn privacy/governance from current official sources. Internship and work experience matter: a roadmap alone is not professional experience.
